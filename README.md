# LogcatDetector 🔍

This plugin provides a project tool window for IntelliJ IDEA that simplifies the process of detecting, filtering, and analyzing Android application logs in real-time.

It helps developers quickly identify crucial log messages by categorizing them based on their severity levels, such as Errors, Warnings, and Info.

By using this plugin, you can focus on debugging your application efficiently and maintaining a smooth development workflow straight from your IDE.
