# LogcatDetector

Ini adalah alat bantu (plugin/aplikasi) yang dirancang untuk mempermudah deteksi, analisis, dan penyaringan log aplikasi Android secara real-time langsung dari lingkungan pengembangan Anda.

Proyek ini membantu developer mempercepat proses *debugging* dengan menangkap pesan error, peringatan, dan informasi penting lainnya secara terstruktur.

Dengan menggunakan alat ini, Anda dapat menghemat waktu dalam melacak *bug* dan menjaga performa aplikasi tetap optimal sejak awal pengembangan.

## Cara Instalasi

* **Secara Manual:**
  
  Unduh rilis terbaru pada bagian *latest release* lalu pasang secara manual melalui menu `Settings/Preferences` > `Plugins` > ikon roda gigi > `Install plugin from disk...`

---

Proyek ini dikembangkan dengan basis teknologi IntelliJ Platform.
