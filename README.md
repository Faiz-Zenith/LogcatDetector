# LogcatDetector 🔍

A powerful and lightweight IntelliJ IDEA plugin designed to simplify, filter, and analyze Android application logs in real-time.

---

## Key Features

* **Real-time Monitoring:** Instantly capture log outputs during the debugging process.
* **Smart Filter:** Easily filter log messages by their severity levels (Error, Warning, Info, Debug).
* **Developer Friendly:** Clean interface integrated directly into your IDE workflow without heavy performance overhead.

---

## Installation

### 1. Manual Installation (Recommended)
* Go to the **Releases** section on the right side of this repository.
* Download the latest `.zip` plugin file from the **Assets** section.
* Open IntelliJ IDEA, then navigate to `Settings/Preferences` > `Plugins`.
* Click the **Gear icon (⚙️)** at the top and select **Install Plugin from Disk...**
* Choose the downloaded file and restart your IDE.

### 2. Development Setup
If you want to modify or build this plugin from the source code:
1. Clone this repository to your local machine.
2. Open the project in IntelliJ IDEA.
3. Sync the Gradle project and use the `./gradlew runIde` command to test the plugin.
